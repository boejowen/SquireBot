Implementation:
- Strip a leading `v` from both inputs (`strings.TrimPrefix`).
- Split each into the `MAJOR.MINOR.PATCH` core and an optional `-prerelease` tail on the FIRST `-`.
- Parse the three core parts with `strconv.Atoi`. Asymmetric failure handling (the load-bearing inversion vs. the watcher's defensive `IsNewer`):
  - If the FLOOR core is unparseable (≠3 numeric parts) → return `false` (our const is misconfigured; never reject a real client over our bug).

- Compare the three core ints in order; first difference decides (`present[i] < floor[i]` ⇒ true; `>` ⇒ false).
- If the cores are EQUAL, apply pre-release precedence (SemVer §11): a version WITH a pre-release tail is older than the same version WITHOUT one. So: present-has-prerelease && floor-has-none ⇒ true; present-none && floor-has ⇒ false; both have tails ⇒ compare the tails with `strings.Compare` (sufficient for our `rcN`/`betaN` scheme — document that numeric-field SemVer pre-release comparison is intentionally simplified to a lexical compare because we only ever publish `MAJOR.MINOR.PATCH` finals; pre-releases are a dev-only safety rail). Equal cores + equal/absent tails on both ⇒ false (not older).
