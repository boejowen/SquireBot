## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| process -> Discord gateway/REST | Outbound WSS + REST; the bot token authenticates us; Discord responses (incl. 50007) are untrusted error states to handle |
| bot goroutine -> HTTP server goroutine | A panic in the bot must not cross into the listener (availability boundary) |
| notify -> alert_log (DM body) | The DM body + item names are user/wiki-controlled text; they are sent to Discord but must never be logged |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-06 | Denial of Service | bot goroutine panic | mitigate | recover() boundary in the goroutine + every (future) handler; non-fatal Start; a bot panic logs and is swallowed - the website/scheduler/ingest survive (LOCKED, Pitfall 7) |
| T-20-07 | Info disclosure | bot token | mitigate | Token read only from os.Getenv(DISCORD_BOT_TOKEN) (EnvironmentFile, Plan 03 deploy doc); NEVER logged (no slog field carries it), never committed, never in the build |
