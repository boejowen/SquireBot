<objective>
Adopt goreleaser to replace the Phase 1 hand-rolled GitHub Actions release pipeline, while preserving the AUTH-03 PRODUCTION consent-screen gate as a workflow PRE-STEP. The new pipeline emits two assets (installer .exe + bare squirebot.exe) plus a latest.json that Plan 02-06's auto-updater consumes. SignPath OSS code-signing is NOT wired in this plan; if Plan 02-09's SignPath application is approved, signing will be added as an additional explicit step in the workflow (not via goreleaser; CI does not invoke goreleaser).

Purpose: Phase 1's release.yml is hand-rolled and brittle — every signing-related change becomes a YAML rewrite. goreleaser consolidates ldflags injection, NSIS invocation, SHA-256, manifest, signing hook into one declarative .goreleaser.yaml. Pitfall F guards us against `goreleaser init` clobbering the AUTH-03 gate.

Output: New .goreleaser.yaml; refactored .github/workflows/release.yml; updated docs explaining the new release flow.
</objective>

The Phase 1 workflow does (in order):
  1. checkout
  2. setup-go
  3. Materialise oauth-config.json from OAUTH_CONFIG_JSON secret
  4. Install NSIS (>= 3.10)
  5. Verify NSIS version
  6. Compute version from tag
  7. Load OAuth constants — INCLUDES the AUTH-03 PRODUCTION gate (consent_screen_status check)
  8. Build squirebot.exe with ldflags
  9. Build NSIS installer
 10. Compute SHA-256 of installer
 11. Write latest.json (manifest)
 12. Upload build artifacts
 13. Create GitHub Release on tag push

Steps 1–7 stay outside goreleaser (workflow steps). Steps 8–13 collapse into one `goreleaser release` step.

The AUTH-03 PRODUCTION gate (step 7) MUST stay in workflow YAML, not goreleaser, because:
  - It depends on a runtime-materialised file (oauth-config.json from a secret).
  - goreleaser config is mostly declarative; runtime checks belong in workflow steps.
  - Pitfall F: `goreleaser init` would clobber this; we hand-author .goreleaser.yaml.

Existing latest.json schema (locked):
```json
{
  "version": "X.Y.Z",
  "installer_url": "https://.../SquireBot-Setup-X.Y.Z.exe",

REPLACE steps 8-13 with the five steps shown here. There is ONE architecture; do not introduce goreleaser-action in CI. CI does explicit go build + makensis + manifest steps; goreleaser is for local snapshot builds only.

    ```yaml
          - name: Build bare squirebot.exe (pre-NSIS, pre-manifest)
            shell: pwsh
            env:
              GOOS: windows
              GOARCH: amd64
              CGO_ENABLED: '0'
              OAUTH_CLIENT_ID:     ${{ steps.oauth.outputs.client_id }}
              OAUTH_CLIENT_SECRET: ${{ steps.oauth.outputs.client_secret }}
              PICKER_API_KEY:      ${{ steps.oauth.outputs.api_key }}
              GCP_PROJECT_NUMBER:  ${{ steps.oauth.outputs.project_num }}
            run: |
              New-Item -ItemType Directory -Force -Path dist | Out-Null
              $ldflags = "-H=windowsgui -s -w " +
                         "-X main.OAuthClientID=$env:OAUTH_CLIENT_ID " +
                         "-X main.OAuthClientSecret=$env:OAUTH_CLIENT_SECRET " +
                         "-X main.PickerAPIKey=$env:PICKER_API_KEY " +
                         "-X main.GCPProjectNumber=$env:GCP_PROJECT_NUMBER " +
                         "-X main.Version=${{ steps.ver.outputs.version }}"
              go build -ldflags="$ldflags" -o dist/squirebot.exe ./cmd/squirebot

          - name: Build NSIS installer (pre-manifest)
            shell: pwsh
            run: |
              & $env:MAKENSIS /V2 /DAPPVERSION=${{ steps.ver.outputs.version }} installer/squirebot.nsi
              if ($LASTEXITCODE -ne 0) {
                Write-Error "makensis exited $LASTEXITCODE"
                exit $LASTEXITCODE
              }

          - name: Compute SHA-256 sums (installer + bare binary)
            id: hashes
            shell: pwsh
            run: |
              $installerPath = "dist/SquireBot-Setup-${{ steps.ver.outputs.version }}.exe"
              $binaryPath    = "dist/squirebot.exe"
              $installerHash = (Get-FileHash $installerPath -Algorithm SHA256).Hash.ToLower()
              $binaryHash    = (Get-FileHash $binaryPath    -Algorithm SHA256).Hash.ToLower()
              "installer_sha256=$installerHash" | Out-File -Append -Encoding utf8 -FilePath $env:GITHUB_OUTPUT
              "binary_sha256=$binaryHash"       | Out-File -Append -Encoding utf8 -FilePath $env:GITHUB_OUTPUT

          - name: Write latest.json (Phase 2 manifest with both URLs)
            shell: pwsh
            run: |
              $version = "${{ steps.ver.outputs.version }}"
              $owner   = "${{ github.repository_owner }}"
              $repo    = "${{ github.event.repository.name }}"
              $manifest = @{
                version          = $version
                installer_url    = "https://github.com/$owner/$repo/releases/download/v$version/SquireBot-Setup-$version.exe"
                installer_sha256 = "${{ steps.hashes.outputs.installer_sha256 }}"
                binary_url       = "https://github.com/$owner/$repo/releases/download/v$version/squirebot-$version"
                binary_sha256    = "${{ steps.hashes.outputs.binary_sha256 }}"
                released_at      = (Get-Date).ToUniversalTime().ToString("o")
                phase            = 2
                signed           = $false
              }
              $manifest | ConvertTo-Json -Depth 4 | Out-File -Encoding utf8 -NoNewline dist/latest.json
              Get-Content dist/latest.json

          - name: Create GitHub Release
            if: startsWith(github.ref, 'refs/tags/v')
            uses: softprops/action-gh-release@v2
            with:
              files: |
                dist/SquireBot-Setup-*.exe
                dist/squirebot.exe
                dist/latest.json
              body: |
                SquireBot ${{ steps.ver.outputs.version }} release.

                SHA-256 sums:
                - Installer: `${{ steps.hashes.outputs.installer_sha256 }}`
                - Bare binary: `${{ steps.hashes.outputs.binary_sha256 }}`

                See [docs/build-and-install.md](https://github.com/${{ github.repository }}/blob/main/docs/build-and-install.md).
    ```
