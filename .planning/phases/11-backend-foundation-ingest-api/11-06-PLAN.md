<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet (HTTPS :443) -> Caddy | The public edge; Caddy terminates TLS and is the only externally-reachable port. |
| Caddy -> Go server (loopback :8090) | Plain HTTP on loopback only; never exposed publicly. |
| OS firewall (VCN + iptables) -> host | Two independent layers both must admit 80/443; a misconfigured layer silently blocks. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11.06-01 | Information Disclosure / Tampering | Plaintext HTTP (no/invalid TLS) exposes uploads + tokens in transit | mitigate | Caddy auto-HTTPS provisions a valid Let's Encrypt cert with modern TLS defaults (V6); the runbook verifies an external curl gets a valid cert. HTTP is redirected to HTTPS by Caddy default. |
| T-11.06-02 | Elevation | The Go server runs as root / with excess privilege | mitigate | systemd `User=squirebot` (a system user, no home) + `NoNewPrivileges=true`; the server binds loopback:8090 (no privileged port - Caddy fronts 443). |
| T-11.06-03 | Denial of Service | The backend vanishes on idle reclamation (Oracle Always Free) | mitigate | Task 2 default-recommends PAYG-within-free-limits (reclamation-exempt, $0); pure-free fallback adds a keep-alive cron. Decision recorded in the runbook (Pitfall 5 / A2). |
| T-11.06-04 | Denial of Service | A reboot leaves the backend down | mitigate | systemd `Restart=always` + `WantedBy=multi-user.target` + `enable`; reboot-survival is an explicit acceptance criterion. |
| T-11.06-05 | Spoofing / Tampering | The firewall is left wide open or silently closed (UFW trap) | mitigate | VCN Security List scoped to 80/443; iptables ACCEPT inserted BEFORE the REJECT (Pitfall 2); UFW explicitly NOT used. Only 80/443 (Caddy) + SSH are reachable; the Go server's 8090 is loopback-only. |
| T-11.06-06 | Information Disclosure | The SQLite file / data dir is world-readable | mitigate | `/var/lib/squirebot` is owned by the `squirebot` system user; the binary runs as that user; default umask keeps the DB file non-world-readable. |

ASVS L1 coverage in this plan: V6 (TLS via Caddy, modern defaults). The application-layer controls (V2/V4/V5/V7) are inherited from 11-03/04/05 and ride on the deployed binary. Backup-at-rest (V6) is 11-07.
