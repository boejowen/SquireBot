# Milestone Archive: v2.1 Requirements — Self-Service Watcher Linking

> **ARCHIVED 2026-06-02.** This milestone shipped (tag `v2.1`). All 9 requirements complete (LINK-01..06 + WATCH-12/13/14). Frozen snapshot; the live `.planning/REQUIREMENTS.md` is recreated fresh for the next milestone.

**Status:** ✅ SHIPPED — opened 2026-06-01, shipped 2026-06-02. Phases 17–18.

**Milestone goal:** Let any guildie link their own watcher from squirebot.quest via Discord login — no maintainer hand-minting + DMing codes — while keeping the watcher credential a static, reusable bearer token (no watcher change).

**Locked decisions (2026-06-01 discussion):**
- **Link code = the bearer token itself (v2.0 model, reusable).** Plaintext shown exactly once at mint (hash-only at rest); the watcher pastes and reuses it forever. No expiry. **No watcher change.**
- **Re-link = additive.** A new code is an additional valid token (multiple PCs); revocation is per-token.
- **Manual `mint-code` CLI removed.** Self-service is the sole minting path (`revoke-code` retained as an ops backstop).
- **HARD CONSTRAINT:** Discord identity at link-time only; never Discord OAuth in the watcher.
