## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12.05-01 | Denial of Service (job hot-loop) | scheduler runJob | mitigate | The cursor advances after EVERY attempt (advance-always, even on error — A2), so a persistently-failing fetch retries on its next cadence window (24h / next Sunday), NOT every 10-minute tick. The per-job `TryLock` mutex prevents a slow job from being launched again concurrently. |
| T-12.05-02 | Denial of Service (unclean shutdown) | scheduler run loop + run-job ctx | mitigate | The `select ctx.Done()` branch (preserved verbatim from the tested skeleton) returns promptly on SIGINT/SIGTERM; the jobs' ctx-aware sleeps unwind on the same cancelled context. `run-job` wires `signal.NotifyContext` so Ctrl-C aborts a long wiki run cleanly rather than wedging the box. |
| T-12.05-03 | Elevation of Privilege / unauthorized trigger | run-job CLI | accept | `run-job` is a local out-of-band CLI with NO HTTP surface (mirrors mint-code/revoke-code) — it requires shell access to the VPS, which is already the trust boundary for the maintainer. It exposes no new network-reachable trigger. Disposition: accept (no remote attack surface added). |
| T-12.05-04 | Information Disclosure | scheduler + run-job slog | mitigate | Logs job name / status / counts / err only (V7) — never raw response bodies or secrets (there are none in this path). |
| T-12.05-05 | Tampering (Off-Google regression) | cmd/squirebot-server imports | mitigate | The "Off Google" invariant is enforced: no oauth2/sheets/drive/google import is added (grep-verified 0), and the static linux/amd64 cross-compile (the deploy artifact) still builds — so the scheduler wiring introduces no Google dependency. |

Spoofing / Repudiation: N/A — no identity or auth surface added (the scheduler is internal; run-job is local). SSRF / secret-leak / SQL-injection: N/A here — the outbound fetch + SQL are owned by Plans 03/04/01 with their mitigations; this plan only schedules + dispatches them. None of the above is severity `high`; none trips `security_block_on: high`.
