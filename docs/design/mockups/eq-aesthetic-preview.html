SquireBot — EverQuest aesthetic preview (6 options)

Throwaway preview mockups generated 2026-05-08. Five themed options (Vanilla / Kunark / Velious / Minimalist / Heavy) plus one explicit opt-out (Sheets default). Each option shows a mock gear_check view tab (cell-based — what Sheets can render) plus a mock search sidebar (HtmlService — full HTML/CSS freedom). Final visual decision happens in Phase 3 — these are just to anchor the conversation. Sample data is fake but realistic for a Velious-era Iksar Shadow Knight guildie.

F. Sheets default

opt-out · no styling

No custom theme — the workbook renders as standard Google Sheets: white background, Arial font, default cell borders. Conditional formatting on the Status column (red MISSING / green OK) is the only color. The search sidebar uses default browser styling with no custom CSS. Useful for printing, exporting, integrations that re-render the data, or guildies who actively prefer a plain spreadsheet.

Mockups are pure CSS approximations of what each direction would feel like as a Sheets workbook + sidebar. Real implementation (Phase 3) would use Apps Script setBackground / setFontColor / setBorder / setFontFamily / IMAGE() for cells, and HtmlService templates for the sidebar. Limitations: Sheets cells can't have background images (so the parchment effect in option E would need to fall back to a solid warm tan + maybe an inline IMAGE() banner). Sidebar has no such limit.
