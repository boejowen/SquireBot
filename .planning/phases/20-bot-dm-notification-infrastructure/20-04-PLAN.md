<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API JSON (alert text/source/detail) -> DOM | Server-provided strings (item names, source labels) rendered in the inbox - must be inert text |
| browser -> notifications API | Cookie-credentialed; the owner is server-derived (the page sends no owner) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-17 | Tampering (XSS) | NotificationRow / NotificationInbox | mitigate | All alert text / source / detail rendered via Svelte {} auto-escape ONLY - never {@html}; the single sanctioned raw-HTML sink (ItemTooltip) is not used here |
| T-20-18 | Elevation/IDOR | prefs/inbox/mark-read calls | mitigate | The page sends NO owner; every wrapper body carries only the relevant id (D-02); the server scopes to the session caller; a 401/403 routes through authGuard to the login/refusal |
| T-20-19 | Info disclosure | unread badge / inbox | accept | The badge + inbox show only the caller's own alerts (server owner-scoped); no other user's data is reachable from this surface |
| T-20-20 | Repudiation | mark-read | accept | Read-state is a convenience flag, not a security control; the server audits the mutation (Plan 03) |
</threat_model>
