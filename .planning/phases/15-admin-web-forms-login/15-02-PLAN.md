## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-06 | Spoofing / CSRF | OAuth callback | mitigate | `state` param generated (crypto/rand), stored in a short-lived httpOnly cookie, and verified equal on callback; a missing/mismatched state → 400 before any code exchange (OAuth CSRF) |
| T-15-07 | Spoofing | session theft / fixation | mitigate | Opaque random session id; stored HASHED (sha256) at rest; httpOnly+Secure+SameSite=Lax cookie; rolling 30-day expiry; a brand-new id minted on every login (regenerate-on-login, no fixation) |
| T-15-08 | Elevation of privilege | non-member admittance | mitigate | Membership = configured guild present in /users/@me/guilds; IsGuildMember fail-closed (empty list/config → false); a non-member gets NO session (AUTH-08) |
| T-15-09 | Information disclosure | Discord client secret | mitigate | Secret is backend-only (systemd Environment=); server-side code exchange (D-04); never in the static bundle, never logged (V7) |
| T-15-10 | Information disclosure | cross-subdomain cookie + CORS-with-credentials | mitigate | Cookie Domain=squirebot.quest (registrable domain → rides apex + api); CORS echoes the EXACT origin (never `*`) + Access-Control-Allow-Credentials:true (the wildcard-with-credentials combination is forbidden and rejected by browsers) |
| T-15-11 | Elevation of privilege | read API without a session | mitigate | RequireSession wraps every read route (the 4 views + meta) → 401 without a valid session; the gate is at the API, not just the SvelteKit frontend (D-01, frontend gating is bypassable) |
| T-15-12 | Tampering | session cookie tampering | mitigate | The cookie value is an opaque random id resolved server-side against the hashed store; a forged value simply fails ResolveSession (no client-trusted claims in the cookie) |
| T-15-13 | Tampering / open redirect | OAuth callback final redirect | mitigate | W-4: the post-callback browser redirect Location is built ONLY from the `webOrigin` server constant (hardcoded `https://squirebot.quest`); the handler never reads a request-supplied `redirect`/`return_to`/`next` param, so an attacker cannot bounce a victim through our trusted callback to an arbitrary host (15-RESEARCH §1) |
