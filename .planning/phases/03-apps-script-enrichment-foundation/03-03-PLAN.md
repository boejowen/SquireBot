  | { ok: true; item: ParsedWikiItem; questLinks: WikiQuestItemLink[] }

### Task 2 — wiki-parser.ts

Pure function `parseItempage(wikitext: string, pageTitle: string): ParseResult`. No side effects, no API calls. Operates on the raw wikitext string from `parse.wikitext.*`.

Algorithm (per RESEARCH §2):
1. If `wikitext.length < 200`: return `{ ok: false, reason: 'wikitext_too_short' }`.
2. Locate `{{Itempage` substring. If absent: return `{ ok: false, reason: 'no_itempage' }`.
3. Extract everything from `{{Itempage` to the matching `}}` (handle nested `{{...}}` braces — naive depth counter is fine; no recursive templates expected per fixtures).
4. Split on `\n|` to get parameter list. First entry is `{{Itempage`; skip.
5. For each param, split on first `=` → trim key + value.
6. Specifically capture: `itemname`, `notes`, `statsblock`.
7. Parse `statsblock`:
   - Split on `<br>` (case-insensitive).
   - Each line: trim → check for `:` → if absent, it's a flag (`QUEST ITEM`, `MAGIC ITEM`, `LORE ITEM`, `NO DROP`, `TEMPORARY`); if present, split on first `:` → key/value.
   - Multi-stat lines (`STR: +2  DEX: -10`): split on `  ` (two spaces) → recurse per-piece.
8. Build `ParsedWikiItem`:
   - `itemname` = template's `itemname` param
   - `page_title` = caller-supplied
   - `wiki_url` = `https://wiki.project1999.com/${pageNameToSlug(page_title)}`
   - `summary` = first 200 chars of `notes`, with wiki-links `[[X|Y]]` rendered as `Y` (or `X` if no display name) and `<br>` stripped
   - `is_quest_item` = statsblock contained `QUEST ITEM`
   - `is_no_drop` / `is_lore` / `is_magic` = statsblock contained corresponding flag
   - `slot`, `classes` (split on space, e.g. `ALL` → `['ALL']`, `WAR CLR PAL` → `['WAR','CLR','PAL']`), `ac`, `weight`, `effect`
   - `wikitext_sha1` = `Utilities.computeDigest(SHA_1, Utilities.newBlob(wikitext).getBytes()).map(b => (b<0?b+256:b).toString(16).padStart(2,'0')).join('')`
9. Harvest quest-item links from `notes`:
   - Regex `/\[\[([^|\]]+)(?:\|[^\]]+)?\]\]/g` against the `notes` body
   - Each match → `{ item_id: <caller-supplied>, item_name: itemname, quest_name: match[1], source: 'notes_link' }`
   - If `is_quest_item`: prepend `{ quest_name: '[in-game QUEST flag]', source: 'in_game_flag' }`
10. Return `{ ok: true, item, questLinks }`.

`pageNameToSlug` (per RESEARCH §2): `name.replace(/ /g, '_')` then `encodeURIComponent`.

- Determinism: same wikitext → same SHA every time.

### Task 3 — refreshWikiItems trigger

The most complex file in Phase 3. Algorithm:

```
function refreshWikiItems():
  start = Date.now()
  budget = 5 * 60 * 1000  // 5 min wall-clock
  props = PropertiesService.getDocumentProperties()
  cursor = props.getProperty('wiki_refresh_cursor')  // null on fresh run
  state = cursor ? JSON.parse(cursor) : null

  itemIds = state?.remaining ?? collectInventoryItemIds()  // dedup union of all inv:* item IDs + their names
  totalItems = state?.total ?? itemIds.length
  failures = state?.failures ?? 0
  successes = state?.successes ?? 0

  log('info', 'refreshWikiItems', { resuming: !!state, total: totalItems, remaining: itemIds.length })

  while (itemIds.length > 0):
    if (Date.now() - start > budget):
      // checkpoint + reschedule
      props.setProperty('wiki_refresh_cursor', JSON.stringify({ remaining: itemIds, total: totalItems, failures, successes, started: state?.started ?? new Date().toISOString() }))
      ScriptApp.newTrigger('refreshWikiItems').timeBased().after(60_000).create()
      log('info', 'refreshWikiItems', { checkpoint: true, remaining: itemIds.length })
      return

    // Process up to N items per inner loop iteration before re-checking time, where N=10
    const batch = itemIds.splice(0, 10)
    for ({id, name} of batch):
      try:
        Utilities.sleep(1000)
        const result = politeFetch(`https://wiki.project1999.com/api.php?action=parse&prop=wikitext&format=json&page=${pageNameToSlug(name)}&redirects=true`)
        if ('error' in result) { failures++; continue }
        const json = JSON.parse(result.body)
        if (json.error) { failures++; continue }
        const wikitext = json.parse?.wikitext?.['*']
        const resolvedTitle = json.parse?.title ?? name
        if (!wikitext) { failures++; continue }
        const parsed = parseItempage(wikitext, resolvedTitle)
        if (!parsed.ok) { failures++; continue }
        // Compare SHA against existing _item_master row
        const existingSha = readItemMasterSha(id)
        if (existingSha === parsed.item.wikitext_sha1) { successes++; continue }  // unchanged, skip write
        // Write _item_master row + _quest_items rows (lock acquired per write)
        writeItemMasterRow(id, parsed.item)
        replaceQuestItemRowsForId(id, parsed.questLinks.map(l => ({ ...l, item_id: id })))
        successes++
      catch (e):
        failures++
        log('warn', 'refreshWikiItems', { item_id: id, error: String(e) })

    if (failures > 0 && (failures + successes) >= 50 && failures / (failures + successes) > 0.5):
      // abort — too many failures
      writeError({ where: 'refreshWikiItems', kind: 'fetch_failures_exceeded',
                  detail: `failures=${failures} successes=${successes}` })
      props.deleteProperty('wiki_refresh_cursor')
      cleanupSelfTrigger()
      return

  // Done — all items processed
  writeMetaRow('_meta', 'last_wiki_summary_refresh', new Date().toISOString())
  writeMetaRow('_meta', 'last_quest_items_refresh', new Date().toISOString())
  writeMetaRow('_status', 'last_wiki_item_count', String(successes))
  clearError()
  props.deleteProperty('wiki_refresh_cursor')
  cleanupSelfTrigger()
  log('info', 'refreshWikiItems', { done: true, successes, failures, totalSec: (Date.now()-start)/1000 })
```

Helpers (in same file or `lib/sheet-helpers.ts`):
- `collectInventoryItemIds()`: iterate all sheets matching `^inv:`, read column D (ID, per Phase 2 inv schema), return dedup-by-id list of `{id: number, name: string}` (name from column B).
- `readItemMasterSha(id)`: lookup row in `_item_master` by `item_id` col, return `wikitext_sha1` value or null.
- `writeItemMasterRow(id, item)`: upsert by item_id (if row exists, update in place; else append).
- `replaceQuestItemRowsForId(id, links)`: delete existing `_quest_items` rows where `item_id == id`, then append all new ones.
- `cleanupSelfTrigger()`: iterate `ScriptApp.getProjectTriggers()`, find any with handler `refreshWikiItems` and `getEventType() === ScriptApp.EventType.CLOCK` AND was created via `.after()` (no good API to detect this — instead, check if the cursor property is null AND there are 2+ refreshWikiItems triggers; delete the extras).

**Tests** (mock UrlFetchApp + SpreadsheetApp + PropertiesService + ScriptApp.newTrigger):
- Happy path: 3 items, all parse cleanly, all written, cursor never set, _meta refresh stamps written
- Resume: cursor=`{remaining:[{id:5,name:'X'}], total:10, failures:0, successes:9}` → processes the 1 item, deletes cursor, writes meta
- Mid-budget checkpoint: 100 items, simulated time exceeds budget mid-loop → cursor written, one-shot trigger created, returns early
- SHA unchanged: existing row's SHA matches parsed SHA → no write to _item_master (verify via call count)
- Per-item parse failure: page returns wikitext too short → failure++, no write, processing continues
- Failure threshold: 51% failures → abort, error written, cursor deleted
- Fetch returns wiki API error JSON: parsed correctly as failure
- Idempotent re-run: completed run started again → cursor=null, processes all items fresh
