## Overview

A small, surgical patch milestone closing v1.0 carry-over debt: the installer upgrade path (NSIS pre-install shim that gracefully stops a running watcher before overwrite), code-enforced officer-only eviction with `_meta.guild_admins` allowlist + admin-management UX, and a meaningful pay-down of test + documentation debt (JSDOM in vitest, 4 net-new sidebar inline-JS test files, MRU search migration to PropertiesService, 8 retroactive Phase 3+4 SUMMARY.md files). No user-facing data flow changed; schema stayed at `_meta.schema_version=3` and `WatcherMaxSchemaVersion=3` across all three phases.

**Timeline:** 2 calendar days (2026-05-11 → 2026-05-12). 63 commits since v1.0.0. +318 LOC Go watcher (14,507 total), +~2k LOC TypeScript (13,266 total — includes new `lib/admin.ts`, `triggers/showAdminMgmtSidebar.ts`, and 8 retroactive Phase 3+4 SUMMARY.md files), +39 vitest tests (297 → 336). Three phases shipped sequentially; one mid-smoke OAuth-scope fix surfaced and retired a latent v1.0 bug (`initiated_by='unknown'` audit-log silent fallback).

## Milestone Summary

### Key accomplishments

1. **Installer upgrade path hardened** — NSIS pre-install shim signals the running watcher to exit gracefully (Windows named-event IPC via new `internal/system` package), polls for process exit up to 10s, falls back to `taskkill /F`; the manual stop workaround in `docs/troubleshooting.md` is retired. Shipped + UAT-verified as tag `v1.0.1` on Azure VM (both `--quit` and legacy paths exercised).

2. **Officer-only eviction enforced by code** — `_meta.guild_admins` allowlist + `_meta.workbook_owner_floor` + `_meta.admin_log` extend-only `_meta` rows; eviction sidebar opener + all 3 `google.script.run` callbacks gated by `requireAdminOrThrow` as first statement; non-admins see "Not authorized" modal + zero writes (verified live in dev-workbook).

3. **Admin-management UX with owner-floor lockout protection** — `showAdminMgmtSidebar` HtmlService sidebar lets admins add/remove peer admins; workbook owner cannot be removed by anyone other than themselves (server-side `'owner_floor_protected'` throw + client-side Remove-button suppression). Visual `(owner)` annotation in peer view.

4. **Sidebar inline-JS test infrastructure** — vitest configured with `environment: 'jsdom'` at top level + `mountSidebar()` helper with indirect-eval + nested-`<script>` extraction; 4 net-new sidebar inline-JS test files (Search, Eviction, Bank-Coin, Char-Info); 5/5 shipping sidebars covered (Admin-Mgmt via Phase 7's trigger-call test). Test count 297 → 336 (+39).

5. **Recent-search MRU survives CacheService TTL** — `searchIndex.ts` MRU migrated from `CacheService.getDocumentCache()` (25-min TTL, document-scoped) to `PropertiesService.getUserProperties()` (durable per-user); enrichment cache sites preserved at `CacheService` (different access pattern, different durability needs). New `vi.useFakeTimers()` 25-min persistence test confirms.

6. **v1.0 documentation debt retired** — 8 retroactive Phase 3+4 SUMMARY.md files landed following the Phase 5 template byte-for-byte; every `metrics.commits` SHA resolves under `git cat-file -e` (0 invented hashes). v1.0 milestone audit's documentation-debt line item closed.

7. **Latent v1.0 OAuth-scope bug surfaced + retired** — `apps-script/appsscript.json` was missing `userinfo.email`; under consumer @gmail.com `Session.getEffectiveUser().getEmail()` silently returned empty. Fix in commit `544bef8`. Side effect: closes the v1.0-era silent `initiated_by='unknown'` audit-log fallback for all post-Phase-7 deploys.
