## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stdin (terminal/SSH) → onboarding | The guildie pastes the bearer guild code over stdin; it must reach credstore without leaking to logs/journal |
| guild_code file → other local users | A static reusable bearer token at rest; must be 0600, per-user, never world-readable |
| WINE prefix tree → walk | Untrusted-shaped filesystem (symlinks into host fs, huge trees) walked during discovery |
| os.Args (--status output) → shared terminal/journal | --status output may land in a shared shell history / systemd journal |
