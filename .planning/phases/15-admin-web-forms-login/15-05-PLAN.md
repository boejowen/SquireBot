Backend write endpoints (15-03, on API_BASE = https://api.squirebot.quest; all need credentials:'include'):
- GET  /api/v1/coin/bank-toons   (login-only) → [{character_id, name, plat, gold, silver, copper}] (null coin where unset). [] if none.
- POST /api/v1/coin              (login-only) body {character_id, plat, gold, silver, copper} → {character, coin:{plat,gold,silver,copper}}. Errors: 400 {"error":"invalid_input"}, 400 {"error":"not_bank_toon"}, 401.
- GET  /api/v1/admin/officers    (officer-only) → {officers:[{discord_user_id,username,avatar,is_floor}], promotable:[{discord_user_id,username,avatar}]}. 403 {"error":"not_authorized"} for a member.
- POST /api/v1/admin/officers/add    (officer-only) body {discord_user_id} → {added:bool, username}. Errors: 403 not_authorized.
- POST /api/v1/admin/officers/remove (officer-only) body {discord_user_id} → {removed:bool, username}. Errors: 403 not_authorized | owner_floor_protected.
- GET  /api/v1/admin/evictable   (officer-only) → [{owner_id, label, char_count}].
- GET  /api/v1/admin/eviction/preview?owner_id=N (officer-only) → {owner_id, characters:[name], grace_until}.
- POST /api/v1/admin/evict       (officer-only) body {owner_id} → {removed_count, grace_until}. Errors: 403 not_authorized | owner_floor_protected.
- POST /api/v1/admin/eviction/restore (officer-only) body {owner_id} → {restored_count}.
