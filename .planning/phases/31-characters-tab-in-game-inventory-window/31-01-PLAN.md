## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-31-01 | Tampering | `parseIconID` on wiki `lucy_img_ID` | mitigate | `parseIconID` does `strconv.Atoi` and returns 0 on any non-numeric/negative/blank input — the stored `icon_id` is ALWAYS a non-negative integer, never an arbitrary string. The client URL is `Item_${int}.png` so no wiki string can inject a path/URL (the type-safety control the security gate requires). |
| T-31-02 | Tampering | migration 00012 | accept | Extend-only `ADD COLUMN icon_id INTEGER` (nullable, no DEFAULT/UNIQUE) — cannot break existing rows; `Down` drops only the new column. No data migration. |
| T-31-03 | Information Disclosure | enrich job logging | mitigate | The job's existing slog discipline (op + count, never row content) is unchanged; icon ids are non-sensitive and not logged per-item. |
| T-31-04 | Tampering | item_master upsert (icon_id) | mitigate | Written only via the parameterized `UpsertItemMasterTx` (`?` placeholders); `item.IconID` is an int bind, never string-concat into SQL. |
