### Task 1 — composeNotes.ts (pure function)

```typescript
export interface ViewRowMin { item_id: number; item_name: string; }
export function composeItemNote(
  row: ViewRowMin,
  summary: WikiItemSummary | null,
  pigparseRows: PigparseRowRaw[], // both directions for this item, may be empty
  questLinks: WikiQuestItemLink[],
): string {
  const parts: string[] = [];
  if (summary?.summary) parts.push(summary.summary.slice(0, 200));
  const wts = pigparseRows.find(r => r.t === 0);
  const wtb = pigparseRows.find(r => r.t === 1);
  if (wts) parts.push(`\nRecent ask: ${formatPp(wts.a30)}pp (30d avg, ${wts.t30} transactions)`);
  if (wtb) parts.push(`Buy posts: ${formatPp(wtb.a30)}pp (30d avg, ${wtb.t30} transactions)`);
  if (!wts && !wtb) parts.push(`\nNo recent transactions on PigParse.`);
  if (summary?.is_quest_item) parts.push(`\nQuest item: yes (in-game flag)`);
  const noteLinks = questLinks.filter(l => l.source === 'notes_link').slice(0, 5);
  if (noteLinks.length > 0) parts.push(`Used in quests: ${noteLinks.map(l => l.quest_name).join(', ')}`);
  return parts.join('\n');
}
function formatPp(n: number): string { return n.toLocaleString('en-US'); }
```

**Tests:** 6 cases covering all branches (summary present/absent × pigparse rows present/absent × quest items present/absent). Note total length under 50KB.

### Task 2 — buildView.ts

Algorithm:
1. Acquire lock (30s timeout).
2. `cache = new Map()`. Load: all `_pigparse` rows into Map keyed `item_id+direction`; all `_item_master` rows keyed by `item_id`; all `_quest_items` rows keyed by `item_id`.
3. List all sheets. Filter to those whose name starts with `inv:`. For each:
   - Char name = sheet name slice(4)
   - Read `getDataRange().getValues()` (skip row 1 header)
   - For each row: emit a view row `[char, slot, item_name, item_id, count, hyperlinkFormulaFor(wiki_url), price, last_synced]`
4. Sort view rows: by Char asc, then by Item asc.
5. Compose 2D array. Single `viewSheet.getRange(2,1,rows.length,8).clearContent()` then `setValues(rows)`.
6. For each row, also accumulate parallel `notes[]` array of strings (composeItemNote per row).
7. Single `viewSheet.getRange(2,3,rows.length,1).setNotes(notes.map(n => [n]))` — sets all notes in one call.
8. Apply conditional formatting on Last Synced column (col 8): clear existing rules, add 3 rules (green/orange/red) per RESEARCH §1 + CONTEXT §Last Synced Conditional Format.
9. `applyTheme(viewSheet, getActiveTheme())`.
10. `writeMetaRow('_status', 'last_view_build', new Date().toISOString())`.
11. Update `view_last_build_ms` in PropertiesService.
12. Release lock.

`hyperlinkFormulaFor(url)`: returns `'=HYPERLINK("' + url + '","wiki")'` or empty string if no url.

**Pigparse direction selection rule (per RESEARCH §3):** for the price cell value, use WTS (`t=0`) row's `a30` if present, else WTB row's `a30`, else empty. The full both-direction info goes into the cell note.

**Tests:** with mocked SpreadsheetApp + 2 fake `inv:` tabs + populated `_pigparse`/`_item_master`:
- 2-tab inventory → view has correct row count
- Sort order is char-then-item ascending
- Item with no `_item_master` row gets blank wiki + price + note "no PigParse data"
- Lock contention → returns early without write
- Debounce: second call within 10s returns early
- Cell notes set on col 3 only
- Conditional formatting rules applied (verify count = 3)
- applyTheme called

### Task 4 — onChange trigger

```typescript
export function onChange(e: GoogleAppsScript.Events.SheetsOnChange): void {
  // Per CONTEXT + PATTERNS §5: only rebuild if the changed sheet is inv:* or spell:*.
  // Phase 2 heartbeat writes to _char_owner + _status; we ignore those.
  const ss = e.source;
  // Apps Script doesn't reliably tell us which sheet changed for OTHER changeType.
  // Strategy: check ALL sheet last-edited timestamps via DataValidation? No reliable API.
  // Pragmatic: rebuild on EVERY change, debounced. The 10s debounce prevents storm waste.
  // Bank rebuild: only if bank_toon_name's inv tab is present (cheap check; no read of all sheets).

  const props = PropertiesService.getDocumentProperties();
  const lastBuildMs = parseInt(props.getProperty('view_last_build_ms') || '0', 10);
  if (Date.now() - lastBuildMs < 10000) {
    log('debug', 'onChange', { skipped: 'debounced' });
    return;
  }
  buildView();
  buildBank();  // safe — no-ops if bank_toon_name unset
}
```

**Caveat documented in plan:** Apps Script's `e` for `OTHER` changes doesn't reliably tell us which sheet was edited. Per RESEARCH §10 gap #2, we accept the over-rebuild cost (~12 redundant rebuilds/day from heartbeats) as worth it for correctness. The 10s debounce caps per-burst cost; the 1h backstop ensures correctness.

**Tests:** 3 cases — first call → builds, second call within 10s → skipped, second call after 10s → builds.

### Task 6 — installTriggers.ts

```typescript
export function installTriggers(): void {
  // Idempotent: delete existing SquireBot-handler triggers first.
  const SQUIREBOT_HANDLERS = ['onChange', 'buildView', 'refreshPigparse', 'refreshWikiItems'];
  ScriptApp.getProjectTriggers().forEach(t => {
    if (SQUIREBOT_HANDLERS.includes(t.getHandlerFunction())) ScriptApp.deleteTrigger(t);
  });

  const ss = SpreadsheetApp.getActiveSpreadsheet();
  ScriptApp.newTrigger('onChange').forSpreadsheet(ss).onChange().create();
  ScriptApp.newTrigger('buildView').timeBased().everyHours(1).create();  // 1h backstop
  ScriptApp.newTrigger('refreshPigparse').timeBased().atHour(3).everyDays(1)
            .inTimezone('America/Los_Angeles').create();
  ScriptApp.newTrigger('refreshWikiItems').timeBased()
            .onWeekDay(ScriptApp.WeekDay.SUNDAY).atHour(4)
            .inTimezone('America/Los_Angeles').create();

  SpreadsheetApp.getUi().alert('SquireBot triggers installed.\n\n' +
    '• onChange: rebuilds view + bank (debounced 10s)\n' +
    '• 1h backstop: catches missed onChange events\n' +
    '• Daily 03:00 PT: refreshPigparse\n' +
    '• Sunday 04:00 PT: refreshWikiItems');
}
```
