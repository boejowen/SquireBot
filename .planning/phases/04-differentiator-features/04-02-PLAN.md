### Task 1 — wiki-spell-types.ts

```typescript
export interface WikiSpellRow {
  class: string;          // 3-letter abbrev from CLASSES
  level: number;          // 1..60
  spell_name: string;     // verbatim from {{SpellRow|name=...}}
  normalized_name: string; // toLowerCase + alphanumeric-only — join key
  last_refreshed: string;  // ISO 8601
}

export type SpellParseResult =
  | { ok: true; rows: WikiSpellRow[]; levelHeaders: number; spellCount: number }
  | { ok: false; reason: 'wikitext_too_short' | 'page_error'; detail?: string };
```

Plus a `normalizeSpellName(s: string): string` helper:
```typescript
export function normalizeSpellName(s: string): string {
  return s.trim().toLowerCase().replace(/^spell:\s*/i, '').replace(/[^a-z0-9]/g, '');
}
```

### Task 2 — wiki-spell-parser.ts

`parseClassPage(wikitext: string, classDisplayName: string, classAbbrev: string): SpellParseResult`

Algorithm per RESEARCH §3:
1. If `wikitext.length < 200`: return wikitext_too_short.
2. Split wikitext on `^==\s*Level\s+(\d+)\s*==\s*$` (multiline) — capture level numbers and section bodies.
3. For each section body, find `{{SpellRow}}` template instances. Within each, extract the `name=` parameter via `\|\s*name\s*=\s*([^\n|]+)`.
4. Trim spell name; compute normalized_name via `normalizeSpellName`.
5. Emit row.
6. Return `{ ok: true, rows, levelHeaders: N, spellCount: M }`.

**Critical robustness (RESEARCH §5 #4):** the `|name=` parameter may not always be the FIRST parameter inside `{{SpellRow}}`. Match it via `\|\s*name\s*=\s*([^\n|]+)` anywhere within the template body, not just first-position.

**Tests** (`apps-script/src/__tests__/wiki-spell-parser.test.ts`):
- Necromancer fixture: parses successfully; levelHeaders=25; emits at least 100 rows; row shape valid; normalized_name is consistent for "Cavorting Bones" → "cavortingbones".
- Paladin fixture: levelHeaders=17; spellCount=66.
- Warrior fixture: levelHeaders=0; spellCount=0; ok=true.
- Empty wikitext: `{ ok: false, reason: 'wikitext_too_short' }`.
- normalizeSpellName edge cases: handles "Spell: Burst of Flame", "Endure Cold", apostrophes ("Numb the Dead"), capitalization.
- (Optional) name-position-robustness: synthetic SpellRow with `|type=...|name=...` ordering parses correctly.

```typescript
function replaceWikiSpellsForClass(classAbbrev: string, rows: WikiSpellRow[]): void {
  const sheet = getActiveSpreadsheet().getSheetByName('_wiki_spells');
  // Read existing class column; bottom-up delete rows where class === classAbbrev
  const lastRow = sheet.getLastRow();
  if (lastRow >= 2) {
    const classCol = sheet.getRange(2, 1, lastRow - 1, 1).getValues();
    for (let i = classCol.length - 1; i >= 0; i--) {
      if (String(classCol[i][0]).trim() === classAbbrev) sheet.deleteRow(i + 2);
    }
  }
  // Append new rows for this class
  const dataRows = rows.map((r) => [r.class, r.level, r.spell_name, r.normalized_name, r.last_refreshed]);
  if (dataRows.length > 0) {
    sheet.getRange(sheet.getLastRow() + 1, 1, dataRows.length, 5).setValues(dataRows);
  }
}
```
