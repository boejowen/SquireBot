# Quick Task 260621-px6: Clean up the dead wantlist code

## Objective

`/api/v1/wantlist*` routes, redirected `/wantlist`→`/wishlist`) but left the old wantlist code behind,
unreachable. The v2.4 milestone audit flagged it (MD-01 + a backend twin). Remove the entire dead
wantlist subgraph — frontend + backend — WITHOUT touching the live code that shares files/helpers with it.

   `webadmin/wishlist.go` (wishlist.go has its own `validWishlist`/`mapWishErr`); only a doc comment references
