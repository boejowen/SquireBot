```go
func mapAssignErr(w http.ResponseWriter, err error) {
    switch {
    case errors.Is(err, store.ErrCharAlreadyAssigned):
        writeJSONError(w, http.StatusConflict, "already_assigned")
    case errors.Is(err, store.ErrCharShared):
        writeJSONError(w, http.StatusConflict, "char_shared")
    case errors.Is(err, store.ErrDuplicateRequest):
        writeJSONError(w, http.StatusConflict, "duplicate_request")
    case errors.Is(err, store.ErrNotAuthorized):
        writeJSONError(w, http.StatusForbidden, "not_authorized")
    default:
        slog.Error("assignment handler", "err", err)
        writeJSONError(w, http.StatusInternalServerError, "internal")
    }
}
```

| Boundary | Description |
|----------|-------------|
| client → member endpoint | Body carries only character_id; identity is caller(ctx). |
| client → officer endpoint | Body carries character_id + (assign) a target assignee + (designate) a mode; ACTOR identity is still caller(ctx); RequireOfficer + in-tx IsOfficerTx gate. |
| non-officer → hidden /admin nav | Nav suppression (UX) is NOT the gate; the route + in-tx re-check are. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-26-08 | Spoofing/Elevation | member claim/release/request | mitigate | `callerID := caller(ctx)`; the decoded body struct has NO discord field (Pitfall 1). A spoofed-identity body is structurally ignored — a test asserts it. |
| T-26-09 | Elevation | officer endpoints hit directly bypassing hidden nav | mitigate | `RequireOfficer` at the route AND `IsOfficerTx` as the store mutator's first in-tx statement (Pitfall 2; the nav suppression is UX only). A non-officer → 403 test on every officer route. |
