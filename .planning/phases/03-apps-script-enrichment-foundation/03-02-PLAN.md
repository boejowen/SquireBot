### Task 2 — politeFetch.ts

Per RESEARCH §5 implementation specifics:
```typescript
export interface FetchSuccess { status: number; body: string; headers: GoogleAppsScript.URL_Fetch.HTTPResponse['getAllHeaders']; fromCache: boolean; etag?: string; }
export interface FetchError { status: number; error: string; retriesUsed: number; }
export type FetchResult = FetchSuccess | FetchError;

const RETRY_DELAYS_MS = [2000, 4000, 8000, 16000, 32000];

export function politeFetch(url: string, opts?: { etag?: string; userAgent?: string }): FetchResult { ... }
```

Algorithm: per RESEARCH §5. `muteHttpExceptions: true` is critical. Honor `Retry-After` header (parse seconds, multiply by 1000, override schedule for that one wait).

`userAgent` defaults to `SquireBot/${VERSION} (+https://github.com/boejowen/SquireBot)`. `VERSION` is read from a constant at top of file (sync this with apps-script/package.json version on each release; can be automated later).

**Tests** (mock `UrlFetchApp` via vitest's `vi.fn`):
- Happy path: 200 response → returns FetchSuccess with body+headers
- 304 Not Modified: returns FetchSuccess with `fromCache=true`
- 429-then-200: retry once, return success, `retriesUsed=1`
- 429 with Retry-After: 5 → wait ~5000ms (verify with mocked `Utilities.sleep`)
- 503 exhausted: 6 attempts, returns FetchError with `retriesUsed=5`
- 4xx (e.g. 404): no retry, returns FetchError immediately
- Network error / throw from UrlFetchApp: catches, returns FetchError

### Task 3 — refreshPigparse trigger

`apps-script/src/triggers/refreshPigparse.ts`:

```typescript
import { politeFetch } from '../lib/politeFetch';
import { parseToRows, PigparseRowRaw } from '../lib/pigparse-types';
import { log } from '../lib/log';

const PIGPARSE_URL = 'https://pigparse.azurewebsites.net/api/item/getall/1';
const PIGPARSE_HEADERS = ['item_id', 'name', 'current_avg', 'last_seen', 'blue_volume',
                         'last_refreshed', 'direction', 't30', 'a30', 't60', 'a60',
                         't6m', 'a6m', 'ty', 'ay'];
const ROW_COUNT_FLOOR_PCT = 0.90;

export function refreshPigparse(): void {
  const lock = LockService.getDocumentLock();
  if (!lock.tryLock(30000)) { log('warn', 'refreshPigparse', { skipped: 'lock_busy' }); return; }
  try {
    const result = politeFetch(PIGPARSE_URL);
    if ('error' in result) {
      writeError({ where: 'refreshPigparse', kind: 'fetch_failed', detail: `status=${result.status} ${result.error}` });
      return;
    }
    const rows = parseToRows(result.body);
    const lastCount = readMetaRowInt('_status', 'last_pigparse_row_count') ?? 0;
    if (lastCount > 0 && rows.length < lastCount * ROW_COUNT_FLOOR_PCT) {
      writeError({ where: 'refreshPigparse', kind: 'truncated_response',
                   detail: `today=${rows.length} last=${lastCount}` });
      return;
    }

    const ss = SpreadsheetApp.getActiveSpreadsheet();
    const sheet = ss.getSheetByName('_pigparse');
    if (!sheet) throw new Error('_pigparse missing — run migrateToV2 first');

    const now = new Date().toISOString();
    const dataRows = rows.map(r => [
      r.i, r.n, r.a30, r.l, r.t30,
      now, r.t, r.t30, r.a30, r.t60, r.a60, r.t6m, r.a6m, r.ty, r.ay,
    ]);
    sheet.getRange(2, 1, sheet.getMaxRows() - 1, PIGPARSE_HEADERS.length).clearContent();
    sheet.getRange(2, 1, dataRows.length, PIGPARSE_HEADERS.length).setValues(dataRows);

    writeMetaRow('_status', 'last_pigparse_row_count', String(rows.length));
    writeMetaRow('_meta', 'last_pigparse_refresh', now);
    clearError();
    log('info', 'refreshPigparse', { rows: rows.length, durationMs: /*…*/ });
  } finally {
    lock.releaseLock();
  }
}
```

Note: `current_avg` (col C) is set to `r.a30` (alias to recent avg) so Phase 2 schema column stays meaningful. `last_seen` (col D) gets `r.l`. `blue_volume` (col E) gets `r.t30`. The new v=2 columns at the right edge get the raw v=2 values.

**Tests** (mock UrlFetchApp + SpreadsheetApp):
- Happy path: fixture loads, 7,240 rows written, lock acquired/released, _meta.last_pigparse_refresh updated
- Lock contention: tryLock returns false → function returns without writing, log emitted
- Truncation: response has 3,500 rows but lastCount=7240 → no _pigparse write, error written, lastCount preserved
- Fetch failure: politeFetch returns error → no _pigparse write, error written
- Migration not run: _pigparse sheet absent → throws clean error (caught by Apps Script's STACKDRIVER)
- Idempotent re-run: running twice in same minute → second run reads new lastCount, all assertions pass
