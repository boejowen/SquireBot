## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → write API (POST /api/v1/wishlist*) | UNTRUSTED body. The owner is session-derived (caller(ctx)), NEVER the body; character_id is untrusted until IsCharAssignedToTx authorizes it in-tx. The HIGH-risk surface — this phase's first mutating writes. |
| EC job → wantmatch → DM | The matcher fans an item match to wishlist owners; the DM target MUST be the want owner, never the character owner. |
| browser → read API (GET /api/v1/wishlist/{char}) | The {char} path is untrusted; it binds only as a `?` placeholder downstream (no SQL built in the handler). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-34-07 | Elevation (IDOR) | webadmin/wishlist.go writes | mitigate | Owner = caller(ctx) (session-derived, body carries no owner); RemoveOwnWishlistTx/SetPingedTx are owner-scoped (silent no-op on a cross-owner id); IsCharAssignedToTx authorizes character_id IN-TX BEFORE the add → 403 on a non-owned char (T-28-05). A guildie can NEVER mutate another's wishlist. THE load-bearing control — tested in Task 2. |
| T-34-08 | Spoofing | wantmatch DM target | mitigate | DiscordUserID is ALWAYS wishlist_item.discord_user_id (the want owner); CharacterName is DISPLAY-ONLY and never affects the DM recipient (T-28-06). The regression test is PORTED in Task 1. |
| T-34-09 | Tampering (SQLi) | readapi/wishlist.go {char} + the matcher | mitigate | The {char} value binds only as a `?` placeholder (compute.WishlistFor → store reads); the matcher SELECTs are `?`-bound; never name-concatenated. Covered-by-design (the inventory.go/RosterFor precedent). |
| T-34-10 | Tampering (input) | the slot enum + item label | mitigate | validWishlist re-validates the slot ∈ the 21 canonical worn slots (server-side, V5) + a non-blank ≤-cap item label — never trusting the client; an unknown slot → 400. |
| T-34-11 | Denial of Service | stale /wantlist routes | mitigate | The 5 retired /api/v1/wantlist* registrations are REMOVED (they would 500 on the dropped wantlist_item table, Pitfall 7). |
