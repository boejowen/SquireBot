## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → HTTP handler | Untrusted JSON bodies + query strings cross here; the session cookie is the only trusted identity source. |
| handler → store | The handler passes `caller(ctx)` (session identity) — never a body-supplied owner. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
