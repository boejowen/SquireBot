### Task 4 — Migration to schema_version=2

`apps-script/src/lib/migrations.ts`: `migrateToV2(): boolean` — returns true if migration ran, false if no-op.

Algorithm:
1. Read `_meta.schema_version`. If `2`, return false. If not `1`, throw — unsupported state.
2. Wrap remainder in `LockService.getDocumentLock().tryLock(30000)` + try/finally.
3. `appendColumns('_pigparse', ['direction', 't30', 'a30', 't60', 'a60', 't6m', 'a6m', 'ty', 'ay'])`.
4. `appendColumns('_item_master', ['wikitext_sha1'])`.
5. `appendColumns('_quest_items', ['source'])`.
6. `writeMetaRow('theme', 'minimalist')` if absent. `writeMetaRow('contact_email', '')` if absent.
7. `writeMetaRow('schema_version', '2')` LAST. After this write, the migration is committed.
8. Return true.

**Critical ordering:** schema_version write is the LAST step. If anything before it fails, the migration is replayed on the next trigger fire. Idempotent.

`apps-script/src/__tests__/migrations.test.ts`: vitest with mocked SpreadsheetApp.
- Test 1: schema_version=2 → returns false, no writes.
- Test 2: schema_version=1, all columns missing → 5 writes (4 appendColumns + 2 setMetaRow + 1 schema bump).
- Test 3: schema_version=1, columns already present (partial prior run) → only schema_version write fires.
- Test 4: appendColumns is idempotent (called twice with same headers → second call no-op).

**Done when:** `npm test -- migrations` passes 4 tests.

### Task 7 — docs/apps-script-deploy.md

Per-workbook setup runbook for the workbook owner (the guild lead, not every guildie):

```
1. Open the workbook → Extensions → Apps Script. (This creates a container-bound script.)
2. Copy the script ID from the URL bar (the long alphanumeric after /projects/).
3. Clone SquireBot repo locally. cd apps-script/.
4. cp .clasp.json.example .clasp.json. Paste the script ID into it.
5. npm install. npm run build. npm test.
6. clasp login. clasp push.
7. Open the workbook → SquireBot menu → Run setup.

Update flow (when SquireBot ships a new Apps Script version):
1. cd apps-script. git pull. npm ci. npm run build. clasp push.
2. The migration runs automatically on the next trigger fire.

Important: ship watcher v0.3.0+ to all guildies BEFORE running clasp push. Older watcher versions will refuse to write to schema_version=2 workbooks.
```

**Done when:** doc lands; reviewed manually for clarity.
